## 🚨 Si Algo No Funciona

### **Pasos de Resolución:**

1. **Revisar la consola del navegador (F12)**
   - Ver errores en rojo
   - Copiar el error exacto

2. **Verificar que dataset.csv carga**
   - Red → Ver si `dataset.csv` aparece
   - Status debe ser 200 (OK)

3. **Limpiar caché del navegador**
   - Ctrl+Shift+Delete
   - Borrar caché e imágenes
   - Recargar (Ctrl+F5)

4. **Verificar configuración en GitHub**
   - Settings → Pages
   - Branch debe ser `gh-pages`
   - Folder debe ser `/ (root)`

5. **Rebuild y redeploy**
   ```bash
   npm run build
   .\deploy.ps1
   ```

6. **Esperar 2-5 minutos**
   - GitHub Pages puede tardar en actualizar
